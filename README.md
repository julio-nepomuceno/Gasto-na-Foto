# Gasto na Foto

Aplicação web simples para ler comprovantes de compra por meio de IA e somar automaticamente os gastos.

## Funcionalidades
- Envio de imagem de comprovante
- Leitura automática dos dados com IA
- Cálculo do total gasto
- Contador de comprovantes processados

## Tecnologias
- HTML
- CSS
- JavaScript
- Puter AI

## Como usar
1. Abra o projeto no navegador.
2. Selecione uma imagem do comprovante.
3. Aguarde a análise da IA.
4. Veja o total gasto atualizado na tela.

## Observação
Este projeto é uma demonstração simples de como combinar uma interface web com inteligência artificial para interpretar comprovantes.
